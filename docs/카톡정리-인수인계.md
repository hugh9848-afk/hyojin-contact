## 5. 작업 방법

카카오톡 검색 결과는 **가로 썸네일 5개 + `더보기(+N)`** 형태라 그대로는 못 씁니다.
`더보기` 를 눌러 **세로 목록으로 펼친 화면**에서 작업합니다. 거기엔 이름이 다 나옵니다.

```
폰:  카카오톡 → 돋보기 → "경기" 입력 → 키보드 내림 → 더보기(+N) 눌러 펼침
맥:  python3 ~/kakao_run.py --list     (아무것도 안 누르고 대상만 보여줌)
맥:  python3 ~/kakao_run.py            (삭제 실행)
→ 검색어를 경기 → 과천 → 성외 → 안양 으로 바꿔 네 번, 각각 --list 가 0이 될 때까지
```

### 한 사람 처리 흐름 (실제 화면으로 확인함)

```
이름 탭 → 프로필 창 → "더보기" → 메뉴(멀티프로필 설정 / 친구 삭제 / 친구 숨김 / 친구 차단)
→ "친구 삭제" → 확인 → "닫기"
```

### 스크립트가 지키는 것

- 좌표를 찍어 누르지 않고 **화면 글자를 읽어** 누릅니다
- 자리를 누른 뒤 **프로필 창의 이름이 예상과 같은지 확인**하고, 다르면 삭제하지 않고
  목록부터 다시 읽습니다
- **`친구 삭제` 메뉴는 매번 글자로 확인**합니다. 못 찾으면 멈추고 화면 글자를 보여줍니다
- 15명마다 `더보기`·확인·`닫기` 자리를 다시 재어 어긋나면 멈춥니다
- 지운 사람은 `~/kakao_정리기록.txt` 에 한 줄씩 남습니다

### 알려진 함정 (이미 고쳐짐)

상태메시지가 있는 사람은 `경기1일 김지우 잘하자!` 와 `경기1일 김지우` **두 줄로 읽힙니다.**
긴 쪽을 집으면 프로필 창 이름과 안 맞아 무한 반복에 빠졌습니다.
→ 한 줄에서 **짧은 쪽(순수한 이름)** 만 쓰고, 이름 확인을 양방향으로 하도록 고쳤습니다.
경기가 40에서 멈춘 것도 이 때문으로 보입니다.

## 6. 폰이 멈췄을 때 — 지금 해야 할 것 ★

`uiautomator dump` 가 끝나지 않으면 스크립트가 통째로 멈춥니다. 짚이는 원인부터:

**① 화면에서 뭔가 계속 움직이고 있음** — `uiautomator` 는 화면이 조용해질 때까지 기다립니다.
카카오톡 친구 목록 맨 위에 **광고 배너**(`광고 한샘 쌤페스타` 등)가 돌아가면 끝나지 않습니다.
→ 광고가 없는 **검색 결과 화면**에서 작업하세요. 그리고 애니메이션을 꺼두면 확실합니다:

```bash
adb shell settings put global window_animation_scale 0
adb shell settings put global transition_animation_scale 0
adb shell settings put global animator_duration_scale 0
```

**② 화면이 꺼짐** — 꺼지면 읽지 못합니다.

```bash
adb shell svc power stayon usb
```

**③ adb 가 꼬임**

```bash
adb kill-server && adb start-server && adb devices
```

**④ 그래도 안 되면** — 폰에서 카카오톡을 완전히 닫았다 다시 열고, USB를 뺐다 꽂습니다.

**진단 순서**

```bash
adb devices
adb shell echo ok
time adb exec-out uiautomator dump --compressed /dev/tty | head -c 200
```

세 번째가 몇 초 걸리는지, 아예 안 끝나는지가 핵심입니다. 안 끝나면 ①번이 원인입니다.
