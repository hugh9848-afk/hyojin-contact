## 작업 방법

카카오톡 검색은 **가로 썸네일 5개 + `더보기(+N)`** 형태라, `더보기` 를 눌러
**세로 목록으로 펼친 화면**에서 작업합니다. 거기엔 이름이 다 나옵니다.

```
폰:  카카오톡 → 돋보기 → "경기" 입력 → 키보드 내림 → 더보기(+N) 눌러 펼침
맥:  python3 ~/kakao_run.py --list     (아무것도 안 누르고 대상만 보여줌)
맥:  python3 ~/kakao_run.py            (삭제 실행)
→ 검색어를 과천 → 성외 → 안양 으로 바꿔 네 번
```

### 한 사람 처리 흐름 (실제 화면으로 확인함)

```
이름 탭 → 프로필 창 → "더보기" → 메뉴(멀티프로필 설정 / 친구 삭제 / 친구 숨김 / 친구 차단)
→ "친구 삭제" → 확인 → "닫기"
```

### 스크립트가 지키는 것

- 좌표를 찍어 누르지 않고 **화면 글자를 읽어** 누릅니다
- 자리를 누른 뒤 **프로필 창의 이름이 예상과 같은지 확인**하고, 다르면
  삭제하지 않고 목록부터 다시 읽습니다
- **`친구 삭제` 메뉴는 매번 글자로 확인**합니다. 못 찾으면 멈추고 화면 글자를 보여줍니다
- 15명마다 `더보기`·확인·`닫기` 자리를 다시 재어 어긋나면 멈춥니다
- 지운 사람은 `~/kakao_정리기록.txt` 에 한 줄씩 남습니다
